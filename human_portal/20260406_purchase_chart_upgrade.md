# 작업 기록 (2026년 4월 6일)

- **작성 시간:** 2026년 4월 6일
- **작업 내용:** 
    1. **매입계산서 현황 UI 개선:** 금액 표시 글자 크기를 매출액과 동일한 2.8rem으로 확대.
    2. **매입 월별 변동 추이 차트 고도화:**
        - 데이터를 '품목비고' 항목별로 분류하여 스택형 막대 그래프(Stacked Bar Chart)로 시각화.
        - 그래프의 막대(특정 월의 특정 항목) 클릭 시, 해당 조건에 맞는 상세 내역이 팝업창으로 뜨도록 구현.
    3. **상세 내역 페이지(`purchase-detail.html`) 업데이트:** 월별 필터 외에 항목(Category) 필터 기능을 추가하여 정확한 데이터 표시.
